# Realtime Fintech Dashboard

Angular application with a live market table and a producer settings page. Market updates are generated by a WebAssembly module running in a Web Worker.

The Wasm module keeps per-instrument prices and the random walk. The application turns those updates into last price, bid–ask spread, trading volume, VWAP, and order-book imbalance.

## Prerequisites

- Node.js with npm

## Install

```bash
npm install
```

## Run

```bash
npm start
```

This builds the Wasm module, then starts the dev server. Open [http://localhost:4200/](http://localhost:4200/).

The dashboard opens with five instruments. Generation starts immediately. **Pause** stops new trades and keeps the current totals. **Resume** continues the same run. Settings on `/settings` stay in the form until **Apply**, which starts a new run and clears the totals.

`ng serve` alone does not build the Wasm module. Use `npm start`.

## Test

```bash
npm test
```

Wasm is built before the tests. The suite covers metric calculations, settings validation, pause/resume, stale runs, and the generator.

## Production build

```bash
npm run build
```

Output is written to `dist/`.

## Wasm build

```bash
npm run build:wasm
```

AssemblyScript source is `wasm-producer/assembly/index.ts`. The command writes `public/market-producer.wasm` and refreshes the byte copy used by unit tests. `npm start`, `npm test`, and `npm run build` run this step automatically.
